# 无效页面与切片质量筛选计划

状态：目标设计，基础离线筛选已在 `../offline_postprocess/` 实现并运行；OCR、完整错误模板库和独立人工质量评估尚未提供。设计日期：2026-11-06；实现记录：2026-11-07。

总体后处理方案见 `../layer_postprocess/PLAN.md`；本计划只负责决定哪些视口、页面区域和切片可进入后续流程。

## 1. 目标与现有不足

复用已采截图和标签，离线、无 VLM、不重新抓取。排除损坏、错误页、严重采集/标注异常及无法形成可训练样本的数据，避免为坏页面反复调框。

现有 min_boxes=10 和越界数量/比例仅是启发式。简单有效页面可能框少，轮播可能合法横向溢出，验证码或错误页可能框多。当前任一视口失败即排除整页的策略应改为按视口、区域和切片保留正常部分。

## 2. 判定状态

- accepted：硬校验通过，没有足够排除证据。
- rejected：明确失败，记录排除范围与证据，不删除源文件。
- review：规则无法判断或约束冲突，进入待检查集合，默认不进入正式训练。

来源字段缺失记 unknown；未知不能冒充正常，也不能单凭未知判坏。规则评分只表示风险，不宣称是概率。

## 3. 两阶段筛选

### 3.1 后处理前

1. 文件与标注：PNG 可解码、JSON 可读、坐标有限、尺寸正确、关键 ID 无冲突、来源索引与指纹一致。
2. 图像内容：按缩略图和纵向条带统计低信息区域、边缘、前景分布与空白连续长度。
3. 错误页：优先匹配已确认的验证码、访问拒绝、服务错误模板；只有疑似样本才考虑本地 OCR。
4. 几何异常：最终目标越界、裁断程度、重叠重复和异常聚集；layout_bbox 横向溢出默认警告，不独立判死。

图片损坏、图像标签不配套可直接排除当前训练对。少量坏节点若可以确定性隔离且不破坏监督，可记录修复；大面积异常或无法保证完整性时排除或待审，不能无记录修补。

### 3.2 后处理与切片后

执行顺序固定为：自底向上小框清理/融合 → 大框清理/分解 → H>2700时DCGen+框布局长度切片 → 切线/可见性微调 → 最终质量检查。原始页预筛在这些步骤之前完成；切片后的检查只涉及局部坐标、可见性与残缺，不重定义对象语义和父子关系；暂不以五层合法性为筛选门槛。

- 检查来源关系、来源覆盖、删除/融合去向、有效对象与 ignore 合法性。
- 检查核心分区覆盖、触发切分后实际裁图高度 900–1800（H≤2700整图例外）、坐标还原、边缘残缺对象和容量约束。
- 正常区域可以保留，坏区域或坏切片单独排除；不强制整个长页连带丢弃。
- 达到规则调整轮次上限仍不合法，退出并记录 constraint_conflict，不靠不断删除目标让规则通过。

## 4. 多证据规则

| 情况 | 可用证据 | 动作 |
|---|---|---|
| 空白或加载失败 | 多条带低信息、有效前景极少、对象极少 | 联合触发；单纯白背景不排除 |
| 验证码/错误页 | 已确认模板、局部 OCR、正文缺失、结构异常 | 高证据排除；单个关键词仅警告 |
| 内容被遮盖或裁断 | 图像局部特征、可得的采集警告、严重几何损失 | 明确时局部排除；证据不足待审 |
| 横向溢出 | 去重后的目标损失、溢出位置与局部裁剪模式 | 排除轮播等合法模式后再判断 |
| 标签缺失或错位 | 目标分布异常、多处边缘/内容不对应、尺寸/来源错误 | 规则只提候选，不凭边缘缺少单独认定 |
| 框太少或太多 | 去重后的有效目标数、内容密度、切片可行性 | 警告或重新切片，不直接删页面 |

现有 clean hierarchy 不含正文，不能假定可以从 JSON 读取整页文本。OCR 是可选局部补充；不用 OCR 时明确报告语义错误页识别覆盖有限。没有质量元数据时，不推断页面稳定、图片已完整加载或遮挡不存在。

大面积照片也可能低纹理，图片边缘也不等于 UI 边界。图像统计只能与其他证据联合；不得把这些代理指标直接当视觉语义真值。

## 5. 判定粒度与数据分组

- 按 observation/viewport 判定，保留同页其他正常视口。
- 只有整页都失败或是确认的整页错误状态，才排除全部对应样本。
- 同页所有视口、切片和分割记录继续共用原划分组，不因只保留部分视口改变 train/val 归属。
- 要求视口配对的下游任务使用独立完整性选项，不将其强加给单图检测训练。
- 跨视口相似度只作为提示，不要求响应式页面在数量、位置和高度上保持相同。

## 6. 审计格式

每个对象记录 scope、status、reason_codes、evidence、missing_evidence、rule_version、config_fingerprint、source_hash。区域级判定额外保存原图 bbox；切片记录 source page 与 crop_id。

建议稳定原因码：corrupt_image、capture_size_mismatch、invalid_annotation、confirmed_error_template、low_content_joint_evidence、severe_target_geometry、unresolved_structure、slice_constraint_conflict。高层原因与细节数值分开，不把自由文本作为唯一机器接口。

聚合报告包括各原因排除量、待审量、按视口保留量、局部挽救数量、缺失证据比例，以及不同阈值对样本和有效目标保留的影响。

## 7. 分割监督资格检查

- 分割模型仅学习“低分辨率完整截图 → 最终水平分割线”，框操作和微调差异只作审计。
- 只有最终切片与边界通过检查时才发布该页最终线标签；检查归一化坐标、线的排序/去重、原图首尾与高度约束。
- 正常无需切分的页面可以使用空线标签；坏页、待审页、切片冲突和未完成处理不能伪装成空线负样本。
- 局部切片被过滤后，不能直接删掉对应分割线冒充完整整页标签；需重新规划并检查全页覆盖，或将该页从分割监督集合中移出。正常检测切片仍可独立保留。
- 窗口兜底、歧义边界和微调结果分层标记质量；历史拒绝候选不自动成为负样本。
- 检查模型输入 resize/padding 与切线映射一致；低分辨率不足以表达相邻边界时记录不足，不能静默合并监督目标。

## 8. 内存与标定

- 流式处理，缩略图和条带统计优先，避免一次解码整个数据集。
- 每张原图只解码必要次数；像素并发受独立预算限制。
- 默认只保存清单、指标与抽样联系表，不复制全图、不重新存完整 DOM。
- 从现有数据抽取正常页、坏页和边界样本，制作缩略图对照表，人工确认后标定阈值。
- 报告坏页检出与正常页误删，按视口、长图/短图分开统计。具体阈值在此之前不视为已验证。

## 9. 测试与验收

覆盖：合法少框页面、合法轮播、正常长图截断、稀疏图片页面、底部留白、整页空白、验证码、包含“403”正文的正常文章、坏 PNG、尺寸错配、单视口损坏、局部坏切片、缺少质量元数据、残缺标注。

保证相同输入和配置结果一致，原图与标签不变，缺失数据有显式状态。确认模板匹配、OCR 及图像统计不会触发网络请求；所有模型能力均可关闭，不依赖 VLM。

## 10. 本地特殊样本对筛选的约束

见../layer_postprocess/SPECIAL_SAMPLES.md。最高2510框样本已结合截图确认为主体由密集表格组成，按任务范围整页排除；759个≤16×16目标包含条目图标/控件；该极端表格页在聚合前整页排除，不再通过表格/行组保留；普通小表格才按内容块代表处理，不能将“有真实内容”误解为必须保留每个小框。天气地图样本有疑似截图/标签状态错位，应标为annotation_alignment_suspect待检，不能断言具体采集根因。

超高image框6例全部为background_image；排除大背景代表不等于页面无效。1800–2700的357个视口按新协议保留整图；不能因超过1800直接判失败。取消五层结构合格作为接受前提，保留关系图无环、引用完整和来源可追溯检查。

分割监督仍需要完整整页最终线；部分检测裁片被剔除不自动允许发布不覆盖全页的线标签。小于等于2700的正常页面可作为无需切分样本；坏页/待审不算负例。

## 11. 内容块粒度下的筛选口径

筛选需要同时保留原子数量与最终检测数量，但不因聚合后目标明显减少或少于旧min_boxes=10而判坏。正文、链接列表、导航、表格和卡片由代表块表达后，内部小文字/链接不再是缺失标签。明确排除细粒度对象不整片ignore；未知或裁断仍按独立质量规则处理。检查重要内容有代表、主图/标题/显著按钮未被误删，不能要求全部原子目标保留。

## 12. 极端密集表格优先排除

网页元素检测不承担密集表格OCR。预筛联合极端目标数量、重复行列结构、单元格数值/文字/细小链接占主导等证据，判定out_of_scope_dense_table。在小框聚合、布局分解和切片之前执行；不得先聚合降低数量再使其绕过此门槛。

已确认正例：curlie-00322976-p002（desktop2510、tablet2506个检测框）；按page_id排除其全部视口，不扩展到整站。截图和标签仍保留，只从任务索引排除。普通小表格、商品网格、正常文章列表作为保留对照。具体数量/占比阈值待对照标定，不以“存在table类”或“框数多”单项判定。

该类页面不生成检测样本或分割训练样本，不作为无需切分负样本。状态使用rejected加明确out_of_scope原因；报告任务不适用与采集/标注损坏两类计数。

## 13. 用户确认的严格空白裁片策略（v3）

处理后任一实际裁图或核心区域为空白/纯色，整个observation/viewport标记rejected，
其全部检测裁片与整页切线标签退出发布；不再局部挽救该视口。这一确认覆盖前文对空白裁片的局部保留建议，
但不连带排除同页其他正常视口。源文件不删除，原始像素及阈值证据保留。

预筛与后筛实现于stages.py并由pipeline dataset统一调度，三份阶段索引明确传递资格。
原始几何合法不意味着CSS responsive已验证；缺乏浏览器状态时仍记unknown。
