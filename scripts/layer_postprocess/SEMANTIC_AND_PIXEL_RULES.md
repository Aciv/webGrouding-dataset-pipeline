# v7：先清理无效深层，再判断必要组合，最后补充像素边界

本模块只处理保存的截图和 hierarchy；不修改采集器、DOM 提取、截图流程或源数据。

## 1. 自顶向下清理

逐次按 parent 推导真实深度，从浅到深检查，每次修改后重算，不沿用原始 layer 数字。

- 第五级及更深、同级数量不超过 `deep_sparse_count=2` 的通用包装：收缩包装并提升子节点，不删除整个分支。
- 有深层后代、只有一个直接孩子的通用包装：收缩，保留子节点和原 bbox。
- 深层很小的低价值叶节点：默认面积不超过 256 px²、最长边不超过 32 px；仅通用空块、未知小块、装饰性图形等可以省略。
- 文本、标题、图片、媒体、可交互控件、表格、列表、命名区域不因数量少或面积小就删除；review 节点也保护。
- 深层控件/媒体内部的小图形不由本步骤随意删除。
- drop 写入来源及 ignore_regions，contract 保留后代。不是删除所有 L5+。

原始候选里仍有有意义的深层、又缺乏可靠收缩依据时，保留为待审树，`schema=unresolved_visual_tree_v1`、`training_eligible=false`，不伪称已经四层。

## 2. 自底向上判断组合必要性

复用既有 normalize/frontier 处理几何冗余、大包装与子区域。保留深层主要内容，停用本流程旧的“超过四级就逐叶删除”兜底。

组合候选按较深家庭优先枚举，必须为现有同父节点的有效子集：

- 如果正好包含某个父节点的全部孩子，现有父节点已表达该组，不新增包装。
- 如果外接框占父框面积 ≥85%，优先复用父区域，不新增近似包装。
- 候选外接框内部若包含过多未选中的兄弟内容，拒绝该组合候选。
- 仅“两个元素相邻”不够；标题内容、图片说明、空间分隔的子组才提出候选。
- 模型接受部分成员后再次检查必要性。无需修改是正常结果。
- 模型分组后，只对产生超深的通用单孩子包装做局部规则收缩，不再全树归一化或任意删除内容。

模型只选择固定候选，不可删节点、移动 bbox、任意重挂。共享成员仍保留唯一 parent；区域矩形的几何交叠不等于成员冲突。

## 3. 子块拆不开的大框：像素候选

在前两步完成后，仅对仍大于截图面积 60% 的非原子 L1 尝试。

参考 [DCGen 官方 utils.py](https://github.com/WebPAI/DCGen/blob/main/utils.py) 中 `ImgSegmentation.cut_img_bbox` 的两类分隔器：

- 软边界：低方差空白窗口，两侧窗口出现更高变化。
- 硬边界：近乎均匀的扫描行之间出现大范围亮度突变。

独立实现，未引入上游浏览器/LLM 依赖，也不是完整 DCGen 流程复现。差异：有符号像素差避免 uint8 相减环绕；局部区域内优先平衡切分；横纵搜索；最多递归 2 次；默认窗口 24px（上游默认 50）；加入现有 bbox 跨线保护。

- `partition_bbox`：图像分析分区，可以包含空白；不是训练框。
- 有现有成员的区域，`target_bbox` 使用成员外接框。
- 无可用子节点时，使用区域内相对边缘背景的前景包围盒提出候选，标记 `pixel_foreground_unverified`。
- 现有图片、控件、文字等原子框不能被切线穿过；只有通用包装可展开。
- 不存在安全切线，或无法得到至少两个有内容的区域：保留大框，记录原因。
- 模型必须明确 accept 一个完整分区；拒绝、未回答或 uncertain 均不执行。不能改坐标或增加分区。
- 接受后以这些区域替换旧包装，而不是在旧包装下再加一层；原有成员/后代仍保留。
- 原图中的大图片、媒体、控件等原子对象豁免，不强行切碎。

像素方法只能提名视觉边界，不证明划分后的语义正确。模型接受也不等于人工真值。

## 模块与配置

- semantic_cleanup.py：自顶向下清理与组合必要性。
- grouping.py：自底向上候选、模型组合执行、局部包装收缩。
- pixel_regions.py：像素分隔、候选提名、批准后的受限替换。
- grouping_pipeline.py：统一流程与日志；grouping_vlm.py：一次请求同时判断组合和像素候选。
- normalize.py 的新 preserve_meaningful_deep 仅由本流程显式开启，旧历史测试保持原默认行为。

像素路径需要 `python3 -m pip install -r scripts/layer_postprocess/requirements-pixels.txt`。
可设 `pixels.pixel_fallback_enabled=false` 关闭；关闭时不导入 Pillow/NumPy。

`config.example.json` 给出阈值。私有 API 配置不自动覆盖。v7 不复用 v5/v6 投票，因为候选与规范已经改变。
