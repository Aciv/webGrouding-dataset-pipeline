# v9：严格排除原始深层细节，聚合下层时替换上层

## 原始 L5+ 在聚合之前筛选

原始层级按输入 parent 链推导，人读第 5 层及更深即原始深度 ≥4；不直接相信保存的 layer 数字。
先固定这个范围，再收缩包装，避免低价值节点被提升后逃过筛选。

严格策略是训练标注粒度选择，不是在证明像素不可见或控件没有功能。

| 深层叶节点 | 默认低粒度筛选条件 |
|---|---|
| 普通文字（非标题） | 面积 ≤4096 px²、宽 ≤256px、高 ≤32px |
| 小链接 | 面积 ≤6144 px²、宽 ≤256px、高 ≤32px |
| 小按钮 | 面积 ≤1024 px²、最长边 ≤32px |
| 小图形 | 面积 ≤1024 px²、最长边 ≤48px |
| 小图片/徽标/头像等细节 | 面积 ≤2048 px²、最长边 ≤64px |
| 空通用小块/未分类小块 | 与普通小文字的几何阈值相同 |

输入框、非小尺寸图片、较大正文、标题不会仅因原始层级深而删除。浅层小节点不受此策略影响。
少量小图片会与重要小图标混淆，单靠几何不能保证语义正确；这里按用户选定的严格粗粒度政策省略并留痕。

如果一个原始 L5+ 通用包装、列表或 unknown 容器的所有子分支都已判为细碎内容，也将它判为低粒度。
删除先逐叶执行，再删除空包装；不会连带吞掉未满足规则的主要内容。

每条操作保留 original_level、bbox、struct、subtype、明确 reason，并进入 postprocess_sources / ignore_regions。
模型仍收到原图与原始框作为历史证据，但当前候选不包含这些已省略目标，不能恢复或重新聚合它们。

重要限制：这些阈值会省略部分真实可点击的小链接/小按钮；“不作为该层训练目标”不等于“没有交互功能”。

## 下层聚合不能只是再加一个父层

普通候选的执行方式改为 `partition_existing_upper_region`：

1. 从上层 P 的孩子中选择有必要组成新区域的一部分下层块。
2. 新区域 G 与 P 同级，承接选中的孩子。
3. P 保留未选中的内容，bbox 收缩为剩余孩子的外接框。
4. 如果剩余孩子已经共同组成一组，直接复用 P，不再建立第二个重复父框。

所有原有成员层级不增加。原来的上层 bbox 在 postprocess_original_geometry 中保留，拆分过程在 region_replacements 中记录。
原子图片、文字和控件 bbox 不因拆上层而改动；原始 datasets 不覆盖。

不拆原本完整的 card、form、table、list、nav、header、footer 等组件，只为组几个相邻节点而增加包装。
上层太小、只有虚拟根可用、整个家庭已被父节点表达：跳过组合。模型看到明确 replacement_plan，判断的是拆上层是否合理。

像素回退仍为明确批准后的固定分区替换，不添加包装层。共享成员维持唯一 parent，框的几何相交本身并非冲突。

## 扩大到上万样本

按路径模式自动清理，而不是要求逐页人工审核。analyze_deep_layers.py 对固定样本批次输出：

- 表格、列表/卡片、不确定控件、内容/表单等路径的分布；
- 旧深层框分别被省略、提升、收缩或保留的去向；
- 只看 L5+ 的旧/新规则对比页；
- 每条规则的实际删除数量，便于抽样检查，而非上万页逐一检查。

仍有深层并不自动证明它是噪声。无法满足四层契约的输出继续显式标记，不伪称可以直接训练。

## 模块与配置

- deep_noise.py：固定原始深度，严格低粒度分类，不读 DOM、不推断可见性。
- semantic_cleanup.py：删除低价值叶子和空包装，其他包装按规则收缩并提升后代。
- replacement_groups.py：上层拆分计划与执行，复用 group/reparent 树操作并断言成员不加深。
- grouping.py / grouping_pipeline.py：候选与执行共用相同替换计划。
- grouping_vlm.py：模型判断固定上层拆分方案，不再默认加一层。
- analyze_deep_layers.py：只读旧/新预览并生成汇总。

已有私有配置不自动覆盖；CLI 当前默认启用严格原始深层策略和替换上层模式。阈值可以在 rules 中设置。
旧版投票不能复用为新版替换批准，避免把“可以组合”偷换成“可以拆开上层”。
