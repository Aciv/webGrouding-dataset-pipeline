# v4：混合深度候选、自底向上分组与第一级面积检查

## 四级约束

第一级为大区域，第二、三级为主要组件和内容，第四级仅保留必要细节。**只有最终第一级**使用面积硬检查：

`root.bbox.width * root.bbox.height / (capture.width * capture.height) > layer1_max_area_ratio`

默认阈值 0.6。分母是整张已保存截图的面积，不是当前视口高度或父节点高度。
第二、三、四级不使用这一硬阈值；第二级图片/表格占父框 80% 是允许的。
省略包装后，新提升的第一级继续检查，不能靠原始 layer 数字绕过规则。

原子图片、图形、媒体、控件有记录在案的自动豁免。其余大框需要分解，或由 VLM 返回对应 ID、`keep_single_component` 和可见依据。
`accepted=true` 单独不足以放行未解决的大框。没有可用子框时不凭空切出训练标签，而是保留候选并要求明确判断。

## 处理顺序

1. 使用原始 hierarchy 的全部可用节点，先去除严重边界残片、处理近同框和重复框。
2. 对超限根节点向下搜索。不同分支停在不同原始深度，得到不同时包含祖先和后代的一组候选节点。
3. 复用完整组件；对碎片，使用标题位置、水平重叠、相邻标题边界和同源父关系，自底向上组合标题/正文/图片/列表。
4. 必要时复用已有 bbox 间隙分组。无法形成有意义分区时不盲目把所有原子节点提升到第一级。
5. 省略被穿过的布局包装，把选定节点或新组提升，重算 parent/layer，再检查新的第一级。
6. 在分组完成之后才收缩过深的冗余路径、记录超过四级的省略细节。
7. VLM 看原图及候选/来源记录，执行可校验修改；规则再次归一，最后审核面积豁免及视觉结构。

这不是从最细文字/星星开始无条件合并，也不等于把原来的第三层统一改成第一层。
图片、控件、正文、已有卡片和栏目都可以成为不同分支的起点。

## 排版 table 与数据 table

不是所有 `struct=table` 都应保留为一个大对象。整页排版 table 的异质行可能对应品牌、导航、正文和页脚。
当前提名条件：至少三行、行高有明显差异、子树包含图像及控件。普通规则行数据表不会因此被直接打开。
这是候选启发式，VLM 仍应审核。规则不能保证正确区分所有老式排版表格与复杂数据表格。
排版行已经成为第一级后，模型不得再次直接拆散多孩子行、把边缘单元格提升成独立第一级；可以在区域内重组。

## 严重裁剪残片

依据保存的 `layout_bbox` 与当前可见 `bbox`，同时满足以下条件才自动省略叶节点：

- 原始框确实超出截图，当前框贴着截图边界；
- 可见面积/原框面积 < 10%；
- 可见框短边 <= 8px。

省略记录进入 ignore_regions。可见约 45% 的商品图片等有效部分不会被这条规则直接删除。
只凭单张截图不判断整个网站响应式是否合格，不补猜截图外的内容。

## 配置和命令

```json
{
  "rules": {
    "layer1_max_area_ratio": 0.6,
    "clipped_fragment_enabled": true,
    "clipped_min_visible_ratio": 0.1,
    "clipped_strip_max_px": 8
  }
}
```

以上合并到现有配置即可，缺省值已生效，不需要修改私有 key 配置。

```bash
python3 -u scripts/layer_postprocess/cli.py \
  --config scripts/layer_postprocess/config.local.json \
  --input ../datasets/pages \
  --output runs/layers-frontier-new \
  --select curlie-00057254/tablet \
  --select curlie-00130403-p001/desktop \
  --select curlie-00130403-p001/tablet \
  --concurrency 3

python3 scripts/layer_postprocess/compare.py \
  --output runs/layers-frontier-new \
  --baseline runs/layers-vlm-03-layout-10
```

`--select` 是相对输入目录的观察目录，可重复；不加则处理所有样本，`--limit` 仍可限量。
只看规则加 `--dry-run`。正式输出附带 `large_region_checks`、模型的 `large_region_decisions`、被拒绝的编辑及所有来源操作。

v4 必须从原始数据重建，不能复用旧版本已经丢掉深层信息的编辑缓存。`--resume` 只跳过同版本已成功页；旧版本结果备份后重新处理。
显式 `--reuse-edits` 指向旧版本会说明版本不匹配，不偷偷复用。

## 当前边界

- 这是混合深度树候选 + 规则组合，不是学习出的视觉聚类器。
- 仍复用原图进行 VLM 审核，没有实现局部图裁剪发送或 DCGen 像素分割。
- 标题标签缺失、跨栏标题、复杂重叠可能造成错误候选。不能用面积阈值证明所有大块都具有相同语义粒度。
- 截断、损坏插件、原始几何不一致和缺失框仍需记录；模型审核通过不等于人工真值。
- 本次代码只改独立后处理模块，不修改采集、截图、DOM 或原数据。
