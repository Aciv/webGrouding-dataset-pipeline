# DOM语义保留、框清理与长图切片计划

状态：目标设计。2026-11-07已在 `scripts/offline_postprocess/` 实现离线框整理、切片、质量索引和统计，并处理当前datasets；切线网络训练及下游检测训练器接入仍是独立工作。2026-11-06依据特殊样本复核修订。中间计算不强制五层；按用户2026-11-07最新确认，最终成品仅保留真实L1–L5。所有页面1800上限、片内重新分组、超大对象概览补测等旧约定仍不采用。

## 1. 最终目标与已确认约束

低分辨率完整截图预测水平切线，映射回原图裁片，由一个检测head统一预测有效框。现有DOM语义和框用于离线目标整理及切线标签生成。DCGen像素分隔与框布局联合规划，不使用VLM/API投票。

- 先自底向上清理/融合无效小框、补建有依据的组件，再删除无意义大包装、分解混合大区域。
- 随后做长度切片，最后只调整切线、上下文、坐标与可见性。
- 清理、融合、分解、切片使用完整中间图；最终导出按融合后的真实parent深度保留L1–L5（depth 0–4），L6以后抛弃，不提升深层节点。
- 只有原图H>2700（1800×1.5）才触发切分；H≤2700保留整图。触发后的裁片以900–1800为范围。
- 切片不改变全局对象身份、类别或父子关系，也不按片内占比重新删除完整有效对象。
- 无法按预算保留的超大对象按任务协议排除监督，保留内部已有独立目标；不增加概览检测路径。
- 训练宽度分桶，沿用配置驱动的split、probe、train、validate入口。

## 2. 数据证据与前提

原样本检查使用的2628个视口均为v13旧后处理输出，现已废弃，不再作为输入或缓存。2026-11-07当前 `datasets/curlie-full-10k/pages` 已有3957个 `dom_visual_rules_6_child_geometry_offline` 候选视口，本次直接从这批数据处理；不从v13恢复已删除对象。

见 [SPECIAL_SAMPLES.md](SPECIAL_SAMPLES.md)：1910个视口H>2700；357个处于1800–2700；31个视口检测目标超过384；最大2510目标来自真实密集表格。6个高度>1800的image目标全部是background_image，分布在两个站点的六个视口。14个极端/正常对照视口经过局部目视检查。

这些发现支持内容块/组件优先的监督粒度。框多不等于页面无效；真实小文字和链接可被聚合代表并取消独立监督。尺寸与角色阈值先在样本对照上标定。

## 3. 输出对象与关系

- 原字段struct/subtype/semantic_role、source_node_ids、源父节点和几何均可追溯。
- 中间结构关系与detection_eligible独立；最终额外按真实derived_depth<5限制输出，不用旧source_layer代替。根部button不强行补假父节点。
- 保留结构节点图和独立检测目标表；片内target通过global_node_id引用整页对象。父节点在片外仍保留全局引用，不提升到root、不重算语义层号。
- 源层号仅供审计。实际派生depth在融合后重算，最终导出用于L5上限；不作为切片容量不足时的临时删框优先级。
- 内部坐标明确为原图CSS像素xyxy；读取既有xywh时显式转换，导出声明格式。
- 删除包装可以在框整理阶段调整派生树关系，记录前后映射；进入切片阶段后锁定整页对象图。

## 4. 固定处理顺序

```text
任务范围预筛（排除极端密集表格页）→ 视口质量预筛 → 来源与几何校验
→ 自底向上小框清理、重复融合、组件整理
→ 无意义大包装删除、混合大区域分解
→ 发布稳定整页对象图与检测资格
→ H>2700时按DCGen+框布局做长度切片
→ 切线/上下文/可见性微调
→ 最终切线标签、crop manifest、质量检查与生成索引
→ 最终L1–L5投影（原融合结果与切线不变）
→ 用保留框重算20%覆盖率，仅标记当前裁片的细节训练资格
→ 精简导出与压缩
```

只使用确定性几何、语义和像素规则；保留未知状态，限制调整轮次。VLM客户端不初始化，旧accepted缓存不作为新规则证明。

## 5. 框清理政策

### 5.1 已确认的监督粒度：内容块与组件优先

单个小文字、小链接、细小图标即使是真实可见内容，也可以是本任务不需要的细粒度信号。目标是识别有用的内容块和组件，不要求逐个识别全部DOM原子对象。本节替代之前“真实文字/链接/图标原则上都保留监督”的建议。

优先级最高的任务范围规则：网页元素检测不承担表格OCR。主体为极端密集表格、目标数由海量单元格/数值/细小链接主导的页面，在任何小框聚合之前标记rejected，reason=out_of_scope_dense_table；不通过切片、行组归并或提升容量将其保留。该规则高于下述常规内容块聚合规则。

处理顺序为：先找到或构建有意义的代表块，再取消其内部细碎对象的检测资格；剩余没有独立组件价值的孤立小碎框直接排除。先降目标粒度，再处理大块和长度切片，不能依赖裁图或384上限强行承载/截断所有细碎对象。

| 场景 | 主要检测目标 | 取消独立监督的细节 |
|---|---|---|
| 主体为极端密集表格的页面 | 预筛排除整个页面，不进入检测/分割训练 | 全部目标退出训练索引，源文件保留 |
| 普通网页中的小表格 | 表格区域、必要的行组 | 单元格数值、小文字链接、小图标 |
| 链接列表 | 同一栏目或紧凑列表组 | 每个小链接 |
| 连续正文 | 段落、正文块 | 单词、行内链接、零碎文本框 |
| 导航 | 整组导航区域 | 密集的小菜单链接 |
| 商品/文章卡片 | 卡片、主图、标题、显著操作按钮 | 日期、作者、小标签、装饰图标 |
| 页脚 | 联系信息块、链接组 | 单个版权字样、政策小链接 |

只有通过任务范围预筛的普通表格，过长时才在大框分解阶段沿行间隙形成连续行组，行组内部不恢复单元格监督。不要为每个细胞式对象新增父框，避免只是将目标数量换一种方式增加。是否保留整表与行组两个尺度须显式配置，默认避免无必要的冗余代表。

实施规则：

1. 优先复用有视觉依据的现有父块；父块仅是冗余包装时不直接采用，应收缩或按内容重新成组。
2. 没有合适父块时，按邻近、对齐、行列连续性、重复排列、共同背景和已有DOM语义聚合。不能仅凭高IoU，也不能跨明显内容边界无限串联合并。
3. 文字/链接/图标混合组通常用block并记录具体subtype；有充分语义的表格/列表可沿用table/list。保留每个源对象的类别与来源，不把混合组伪装成单一text。
4. 聚合后被代表的小对象设detection_eligible=false，并记录represented_by与reason=represented_by_content_group，不进入Hungarian匹配、框损失、类别正样本或容量计数。
5. 无合适组且无独立组件价值的小文字/小链接直接标drop_fine_grained_noise；显著标题、独立主操作按钮、主图等作为明确例外保留。尺寸、内容角色、重复密度及是否已被上层表达共同判定，16×16和8×8只是统计参考。
6. 明确排除的细粒度类型不自动生成ignore。这些对象无需单独预测；背景/无目标训练按新目标集合执行。ignore仅用于不确定、残缺、标注缺失等情况，避免全页被细碎ignore覆盖。
7. 源对象和关系可保留在结构/审计图；取消监督不是删除来源。框整理完成后锁定派生对象图，切片不重新恢复内部细节、不改关系。
8. 对明确标签错位仍走质量检查，不能用粗粒度聚合掩盖截图与标签不一致。

抽样标定必须把2510框密集表格作为整页排除正例，并包含普通小表格作为保留对照，以及卡片日期/作者、链接导航、页脚及正常标题/主按钮。报告原子目标数、聚合代表数、被吸收数、孤立噪声删除数、重要对象误删数，不以原子框保留率最高为优化目标。重要内容是否被代表与细碎目标是否保留分开评估。

### 5.2 大框与超大目标

- 无意义包装删除其检测资格或收缩包装，保留独立子对象。
- 混合大区域依据子对象分布、空隙、背景分界拆成有意义区域；新区域来自内容证据，不把任意裁片外边界作为正样本。
- 先尝试在正常切片内完整容纳有效对象。对切分页面中确实无法完整容纳的超大目标，按用户确认的目标范围排除完整框监督，记录drop_oversized_target及原bbox。
- 原图H≤2700保持整图，不能因其中某框高于1800就机械删除；超大判定必须考虑实际输入是否容纳。
- 大背景框内部目标既检查DOM后代，也检查全部现有目标的空间关系；无直接子节点不等于没有内容。
- 不新增父级/概览检测分支。大图里的未标注像素内容不能自动生成文字/控件GT；存在标注不完整的片区用明确ignore或排除该检测样本，不能把有效已标注子目标一并屏蔽。
- 上述抛弃针对目标，不自动抛弃整张图片。源节点与关系可在结构/审计图保留，防止丢失可追溯性。

## 6. DCGen+框布局切片与微调

### 6.1 触发、候选与规划

H≤2700直接使用整图；H>2700才规划全宽水平切线。实际裁片900–1800，目标高度1350只是可调偏好。模型、规则基线、训练和验证共享这个门槛，单位为原图像素。

候选来自子框间隙、模块边界以及DCGen式低方差空白带/背景变化。保护真实内容边界，不让无意义大背景包装阻挡全部切线。密集表格优先行间空隙；多栏内容不要求先切成二维区域。

全局/有限前瞻规划避免尾部碎片，联合切断惩罚、边界证据与高度要求。正常视觉边界优先；窗口回退标记fallback。核心分区无重叠且完整覆盖原图，实际裁图可有上下文重叠，但加边后仍检查1800上限。

### 6.2 保持关系的裁图

每个裁片保存page_id、core_bbox、crop_bbox、坐标变换、global_node_id列表与可见性。框坐标变化只是从全局到局部的映射，不改类别、语义关系或全局框定义。

完整对象可在多个重叠裁图中出现，标记归属和重复来源；边缘残缺不变成新的完整对象，使用明确的监督资格或ignore。局部微调可以移动切线、调整上下文、修正坐标误差，不重建父子结构，不按片内面积给对象换身份。发现真实语义错误时，另发派生整页标签版本并同步重生成相关裁片。

### 6.3 容量和效率

训练按宽度分桶并复用probe规则；不在后处理中另设五层训练器。对384容量，优先尝试范围内更短裁片；若900高度仍超容量，报告dense_capacity_conflict，不静默按层号删框。样本显示密集表格900窗口中心数可接近365，实际分配还须计入上下文和完整框。

记录单片与每原页面的计算/样本数量，避免重叠样本过多。H≤2700的超密页面单列容量冲突，不私自突破切分触发协议。

## 7. 分割模型：低分辨率整页截图 → 最终分割线

### 7.1 已确认的任务边界

输入是原始截图缩小后的完整页面，输出是原图上从上到下排列的水平分割线。第一版只做长页面纵向切片，不要求模型预测框、DOM、视觉层级、父子区域、操作历史、分解顺序或微调差异，也不采用“给父区域递归预测切分动作”的任务定义。

训练和推理均只向模型输入截图像素及必要尺寸/有效区域信息。DOM 语义、真实框和后处理视觉树仅用于离线生成监督，不能作为模型推理输入。

```text
标签生成：现有框 → 小框清理/融合 → 大框清理/分解
          → 长度切片 → 微调与检查 → 最终水平分割线
训练：低分辨率整页截图 → 预测最终水平分割线
推理：低分辨率整页截图 → 预测线 → 高度约束解码
      → 映射回原图 → 按原分辨率切片 → 同一全框 head 检测
```

长度切片阶段第一版采用全宽水平分割，不启用局部多栏裁切或不贯穿整页的切线；复杂多栏布局仍可以用于框的语义整理，但不引入另一套分割模型标签。未来需要二维切分时另开协议，不混入本版训练。

### 7.2 低分辨率输入与坐标映射

- 保留完整页面，等比缩小，不先裁成局部块；不把长图当作普通图片强制压成正方形。
- 缩放预算、插值方法、允许的尺寸及 padding 策略放入分割训练/验证配置；先用样本评估分隔带可见性和内存，再选最终尺寸。
- 保存 original_width/height、resized_width/height、实际 resize 参数、padding 偏移和有效像素范围。横向分桶与 padding mask 不改变切线原图坐标。
- 规范标签使用 u = y_original / original_height，且 0 < u < 1；原图首尾 0、H 是隐式边界，不作为模型需要预测的切线。
- 模型预测先去除 padding 坐标影响，再映射到有效缩小图和归一化坐标。原图切线 y = round(u × H)，校验、排序、去重后用于原分辨率裁图。
- 例如 1440×8000 原图缩为 180×1000，原图切线 1600、3200、4800、6400，对应低分辨率行 200、400、600、800，归一化标签 0.2、0.4、0.6、0.8。

### 7.3 监督标签与审计严格分开

分割模型仅使用最终通过检查的切线集合。标签以“每个原始页面视口一条”保存，不是每个裁图或每条处理动作一个训练样本。

```json
{
  "schema": "gui_page_cut_lines_v1",
  "page_id": "page/desktop",
  "image": "pages/page/desktop/full.png",
  "original_size": {"width": 1440, "height": 8000},
  "axis": "y",
  "cut_lines_original_px": [1600, 3200, 4800, 6400],
  "cut_lines_normalized": [0.2, 0.4, 0.6, 0.8],
  "needs_split": true,
  "height_constraints_px": {"trigger_above": 2700, "min": 900, "max": 1800},
  "label_status": "rule_generated_unverified",
  "supervision_eligible": true,
  "source_hierarchy_sha256": "<sha256>",
  "rule_version": "<version>",
  "config_fingerprint": "<sha256>"
}
```

needs_split 是从最终标签派生的样本属性，不要求再增加一个预测 head。正常无需切分的整页用空切线数组；标记 rejected/review 的页面、无安全解或尚未完成微调的页面不能用空数组冒充“无需切分”负样本。

以下仅为审计或裁图管理，不作为分割模型的预测目标：

- operations：小框删除/融合、大框收缩/分解、归属调整及来源映射。
- partition trace：初始切线、候选切线、拒绝证据、微调前后差异与停止原因。
- crop manifest：core_bbox、实际 crop_bbox、重叠/上下文、目标和 ignore 的坐标变换。

每条审计操作标记 stage，区分 small_box_bottom_up、large_box_cleanup_split、length_slicing、post_slice_refinement。大框的语义拆分线不能直接拼进最终截图分割线；模型学习最终切片边界，不学习所有历史边界。

核心切线集合定义全宽、无重叠且完整覆盖页面的分区。检测裁图可以在此基础上补充上下文和重叠，但扩边不是第二套切线标签，实际裁图仍需满足配置约束。

### 7.4 输出表示、训练与约束解码

第一版可采用沿页面高度的一维边界置信度图，训练目标由最终归一化切线生成窄带软标签；允许等价的可变数量坐标输出，但评估与导出统一到上述切线 schema。具体网络单独实现，不在本次计划更新中假定已有可用模型。

- 软标签宽度与匹配容差需要明确原图/缩小图单位，并随实际 resize 转换；不能用同一个低分辨率像素容差比较所有长图。
- 损失平衡稀疏切线与大量非切线位置，padding 不参与损失；横向增强不得改变纵向标签，纵向缩放必须同步转换，默认不启用破坏整页结构的随机裁剪。
- 相邻真实线映射到同一输出单元或窄空白带在缩图后消失时，记录分辨率不足，调整输入/输出分辨率或停用该监督，不能静默合并两个目标。
- 推理先产生候选峰，再用原图高度约束选择有序线集合，确保相邻边界（包括 0、H）形成 900–1800 的核心片段；原图高度不超过2700时不切分。
- 高度不超过 2700 的页面保留整图，1800–2700不触发1800上限；高度严格超过2700的页面的切线数量由高度可行性和预测分数共同确定，不固定每张图的输出数量。
- 约束解码只访问预测、像素和尺寸，不访问真实框。分割线候选不足时启用已声明的纯像素或确定性高度分割回退，并记录 fallback；模型无法单凭高度保证不切断语义对象。
- 模型原始输出、约束解码结果与回退结果分开统计。若所有可行解都不满足质量条件，保留冲突状态，不能通过修改 GT 隐藏失败。

### 7.5 标签质量与验证

- 规则生成的是伪标签，不是人工真值。高可信边界进入主训练；窗口兜底、歧义、强行切断完整对象的样本分开标记，是否加入由显式配置决定。
- 被拒绝的历史候选不自动作为负标签，微调前的切线不成为额外正标签。
- 固定规则及阈值后再生成验证标签；如用训练数据调阈值，不能再把同批人工确认样本宣称为独立验证集。
- 同页所有视口、检测切片和分割标签共用原页面/站点分组，先分组后展开，不允许同图不同派生版本跨训练验证集。
- 在原图坐标上对预测切线与最终参考线一对一容差匹配，报告 precision、recall、F1、位置误差及切线数量误差；等价可用边界不能只因偏离单个参考像素就全部判错，另报告边界可用性。
- 另报告高度约束满足率、回退率、有效对象切断率、完整覆盖率和最终检测指标。真实框可以用于离线评估切断率，但不能用于验证时生成或修正预测线。
- 可视化同时画原图上的参考线、原始预测线、解码后的最终线，检查缩小图坐标映射和尾片。

## 9. 实施和验收

1. 确认处理前hierarchy来源；版本、索引、来源审计先落地。
2. 用SPECIAL_SAMPLES中的密集表格、错位地图、卡片网格、背景大框及正常对照校准去噪规则。

5. 接入宽度分桶probe/训练、低分辨率整图切线模型和原页验证。

回归必须覆盖H=899/900/1800/1801/2700/2701/8000；H≤2700整图例外与长图裁片范围分别检查。覆盖超大背景有/无DOM子节点、片外父引用、重叠目标、真实小图标、零碎噪声、容量冲突。原文件不变，所有删除/融合/分解均有去向；裁图不修改全局对象图。

固定原验证页面64张，每5epoch评估；推理切线不可读取GT。报告原任务与清理后的目标协议差异、有效对象保留、异常页面损失、超大框排除、最终线质量与实际检测效果。

## 11. 后续确认与v2落地

用户确认允许少量组件/包装框在切片边缘损失，不要求为保全全部包装增加裁片。
